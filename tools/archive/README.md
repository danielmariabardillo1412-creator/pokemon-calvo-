# Herramientas archivadas

`pokeapi_adapter_v2_legacy.py` es el adaptador PokéAPI anterior a DATA FOUNDATION V3. Se conserva únicamente por trazabilidad histórica: contiene rutas locales absolutas y no debe usarse para regenerar el dataset actual.

El adaptador canónico es `../pokeapi_adapter_v3.py`. Documentos históricos pueden mencionar la antigua ruta `tools/pokeapi_adapter.py` porque era correcta en la fase que describen.
