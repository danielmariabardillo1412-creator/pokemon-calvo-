# HISTORIAL TÉCNICO

Esta carpeta conserva evidencia y documentación válida para fases anteriores **sin presentarla como estado operativo actual**.

## Contenido

- `phase_reports/` — informes finales de fases cerradas.
- `legacy_data/` — documentación/auditorías de DATA V1/V2 y coberturas anteriores a DATA FOUNDATION V3.
- `research/` — investigación técnica cerrada y referencias externas preservadas.
- `worklogs/` — diarios/cuadernos de ejecución que ya no deben usarse como estado vivo.
- `STATUS_PHASE_HISTORY.md` — antiguo estado acumulativo del proyecto.

## Worklogs

### `worklogs/data_v3/`

Conserva los antiguos cuadernos detallados de DATA V3 (movimientos, familias de habilidades, items, evoluciones y cierre end-to-end).

La consulta normal debe hacerse mediante:

`../project_book/DATA_V3.md`

Los worklogs se usan cuando hace falta reconstruir una decisión o una certificación concreta.

### `worklogs/pre_consolidation/`

Conserva los antiguos documentos operativos de `docs/notebooks/` anteriores a la reorganización. Pueden estar desactualizados por diseño y no son autoridad actual.

### `worklogs/documentation/`

Conserva el cuaderno de ejecución de la propia reorganización documental.
