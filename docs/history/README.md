# Historial técnico

Este árbol conserva documentación válida para fases anteriores sin presentarla como estado operativo actual.

- `phase_reports/`: informes de cierre de fases.
- `legacy_data/`: documentación y auditorías de los pipelines DATA V1/V2 y coberturas anteriores a DATA FOUNDATION V3.
- `research/`: investigación y referencias externas que justificaron decisiones técnicas.
- `STATUS_PHASE_HISTORY.md`: antiguo estado acumulativo del proyecto.

Para el estado actual prevalecen `../STATUS.md` y `../DATA_FOUNDATION_V3.md`.
