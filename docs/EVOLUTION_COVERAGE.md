## Design notes
- `classify_record(record)` returns one of RUNTIME_SUPPORTED, DATA_ONLY, UNSUPPORTED, PARTIAL.
- `evolution_candidates(species, context, catalog)` returns edges whose trigger is satisfied by context
  (e.g. {"level": 16} for level-up, {"held_item": ...} / {"trade": true} for others).
- `apply_evolution` rebuilds a CreatureInstance with the target species: preserves instance_id,
  level, ivs, evs, nature_id, friendship, moveset (and persistent PP), ability (kept if the new
  species also has it), then recomputes stats from the new base and clamps HP to the new max.
- No edge is promoted to runtime merely because PokeAPI lists a trigger - coverage is honest.
