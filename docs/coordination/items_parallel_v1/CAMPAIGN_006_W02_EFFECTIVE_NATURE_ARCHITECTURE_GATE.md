## Decisión funcional IA6

**Separar naturaleza original de naturaleza efectiva para estadísticas.** `CreatureInstance.nature_id` debe preservar identidad/naturaleza de nacimiento y seguir mostrándose como tal. Campo opcional propuesto `effective_nature_id: StringName = &""` o equivalente con valor vacío que signifique «sin menta»; la naturaleza usada por `StatCalculator.compute` será la efectiva válida cuando exista, o `nature_id` de lo contrario. Aplicar menta sustituye solamente la naturaleza **efectiva para modificadores estadísticos**, sin cambiar `nature_id`, especie, identidad, IV/EV ni otras reglas que usan naturaleza original. Ejemplo `lonely_mint` +Atk/-Def con naturaleza original distinta. Para menta neutra `serious_mint`, usar naturaleza efectiva seria, no vaciar el estado salvo «sin menta».

**Compatibilidad obligatoria:** snapshots antiguos sin campo efectivo recuperan naturaleza original; el nuevo campo se valida con `ProgressionRuleset.is_valid_nature` antes de aceptar/guardar; persistencia debe resistir SaveV2 y una recarga sin recalcular datos contradictorios. Para cada operación, candidatas de estado e inventario y ausencia de efecto deben conservar exactamente cantidad/datos ante rechazo; consumo 1 solamente tras cambio efectivo válido y persistible. No alterar estadísticas de PS máximo por naturaleza (PS no recibe multiplicador), ni restaurar PS indebidamente.
